# @mindpeeker/judging

## 0.2.0

### Minor Changes

- New package, first release on npm. Exact scoring and null distributions for forced-choice and free-response psi experiments, depending only on `@mindpeeker/negentropy/numerics`: direct hits with exact binomial tails and Rosenthal–Rubin π, beta-binomial Bayes factors, the closed-deck Zener matching distribution, Read's optimal-feedback baseline, sum-of-ranks convolution, rank-matrix permutation tests, figure of merit, Soal/Bartlett displacement variance, and baselines for multiple looks and optional stopping. Every p-value comes from the randomization of the design; whether psi exists is a contested hypothesis the package does not assert.

- Updated dependencies
